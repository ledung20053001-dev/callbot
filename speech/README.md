# Day 1 — Vietnamese STT foundation

This directory contains provider-neutral STT contracts and a synthetic fixture
set for Vietnamese clinic-call flows. It contains no real patient information.

## Contents

- `docs/stt_adapter_spec.md`: adapter input/output and stable error semantics.
- `docs/normalization_rules.md`: safe normalization policy for identity fields.
- `docs/stt_candidate_comparison.md`: shortlist and Day-2 benchmark rubric.
- `samples/metadata.jsonl`: manifest for 24 synthetic samples.
- `samples/{names,dob,styles,noise}`: generated PCM WAV fixtures.

## Regenerate the fixture set

The checked-in WAV files are generated artifacts. To reproduce them:

```powershell
python -m pip install edge-tts==7.2.7 imageio-ffmpeg==0.6.0
python scripts/generate_audio.py --generate-audio
```

To update the manifest without network access:

```powershell
python scripts/generate_audio.py --metadata-only
```

Verify all paths and WAV headers:

```powershell
python scripts/generate_audio.py --verify
```

The generator uses fixed scripts, deterministic noise seeds, two Vietnamese
synthetic voices, and outputs mono signed 16-bit PCM WAV. Most samples are
16 kHz; three explicit phone fixtures are 8 kHz. TTS voice output itself can
change upstream, so benchmark results should record file hashes.
The manifest includes the generated byte size, duration, and SHA-256 hash.

a substitute for consented, representative telephone speech in a production
quality evaluation.
